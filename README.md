# Recap

Paste a YouTube link, get the conclusion first — then the evidence, the numbers, and the timeline, each with a timestamp you can tap to verify.

- Serverless PWA. Bring your own Gemini API key; it stays on your device.
- Gemini reads the YouTube URL directly (public videos only) → timestamped transcript → structured summary in Korean (or the video's language).
- Short / Standard / Detailed versions are re-written from the saved transcript — no second video pass.
- Everything is stored in the browser (IndexedDB). Export/import JSON to move between devices.

Live: https://nij-621.github.io/recap/
